\section{Özet}

5+ yıllık uçtan uca dijital uygulama, API tabanlı sistem ve veri akışı geliştirme deneyimine sahip Yazılım Mühendisi. Çalışmalarım arasında Python ve SQL ile arka yüz servisleri, PostgreSQL ve Oracle DB veri modelleme, güvenli kimlik doğrulama akışları ve 500+ eşzamanlı kullanıcı için performans optimizasyonu bulunmaktadır. Ayrıca yapay zekâ model ve API entegrasyonu, otomatik içerik iş akışları, Docker ile konteynerize dağıtımlar ve gömülü sistemden mobile veri akışları üzerine çalıştım. Fizik ve bilimsel hesaplama temeline sahibim.
