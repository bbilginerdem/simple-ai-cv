\section{Özet}

Fizik ve bilimsel hesaplama temeline sahip, sistem mimarisi, API entegrasyonu ve uçtan uca yazılım geliştirme alanlarında 5+ yıl deneyimli Yazılım Mühendisi. Yapay zekâ model ve API entegrasyonları, Python ve FastAPI ile arka yüz servisleri, Arduino ile donanım ve gömülü sistem otomasyonu ile karmaşık veri akışlarının tasarımı konularında deneyimlidir. Python, SQL, modern web mimarileri ve Docker ile konteynerize sistem dağıtımlarında yetkindir.
